certificate

A PKI certificate for unique identification. These kinds of certificates are common on Websites, but can also be used to identify applications and people.

certificate repository

A location for storing and organizing PKI Certificates. This organization will identify certificates that you trust from those that you explicitly do not trust etc.

Local Discovery Server (LDS)

A UA Local Discovery Server is the equivalent of OPCENUM (in OPC Classic) and is responsible for providing a list of UA Servers/Gateways that are accessible on the PC where the LDS is installed.

OPCENUM

OPC Classic service responsible for returning a list of OPC Classic Servers installed on the local PC. This service was a work-around for the inability to remotely access the Windows registry back in the late 1990's.

platform independent

Application source-code that can be compiled to work on different platforms such as Windows, Linux, iOS, Android, or embedded etc.

trust

The need for an application to trust another application. Trust is established via PKI Certificates. Applications that do not trust each other can reject connections to each other depending upon the security methods used.

UA Client

An OPC Client that supports a UA interface for connecting to OPC UA Servers.

UA Servers

An OPC Server exposing an OPC UA interface.
