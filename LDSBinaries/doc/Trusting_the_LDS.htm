Trusting the LDS

UA applications (Client and/or Server) must trust The need for an application to trust another application. Trust is established via PKI Certificates. Applications that do not trust each other can reject connections to each other depending upon the security methods used. the LDS in order to use it.
The process is quite simple, and may vary depending on the application you are using. Any of the following steps are plausible:

  1. Simply connect your application to the LDS and expect the first time to fail:

    1. The application might prompt you to accept the certificate A PKI certificate for unique identification. These kinds of certificates are common on Websites, but can also be used to identify applications and people.; if so, then accept it.

    2. The application might store the certificate in the rejected folder, just as the LDS does. In this case you could simply move the file from the rejected store to the trusted store.

  2. Copy the LDS certificate (*.DER) from pki/own folder into the Client/Server application's trust list.
