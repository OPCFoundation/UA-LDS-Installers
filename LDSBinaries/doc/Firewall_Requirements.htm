OPC UA Local Discovery Server 1.02

Firewall Settings

The LDS is a service that exposes endpoints for UA Clients and Servers to connect to. Servers will register themselves with the LDS. Clients will query the availability of Servers. For this to work, the local Firewall(s) must permit traffic to reach the LDS.

Here are some suggestions for Firewall exceptions:

  • Add the LDS executable (tcp/udp; all ports)

  • 52601, for the HTTP protocol

  • 4843, for the HTTPS protocol

  • 4840 , for the TCP Binary protocol.
