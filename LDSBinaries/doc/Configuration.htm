OPC UA Local Discovery Server 1.02

Overview

To maintain platform independence, the Local Discover Server configuration is stored in an XML file which is also well documented.

Configuration File Location

  • Microsoft Windows: C:\ProgramData\OPC Foundation\Config\ualds.ini
  • Linux: /opt/opcfoundation/lds/etc/ualds.conf
