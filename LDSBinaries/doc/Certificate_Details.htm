Viewing Certificate Details

Trusting an application is a straightforward process, but determining the server name from a certificate A PKI certificate for unique identification. These kinds of certificates are common on Websites, but can also be used to identify applications and people. whose filename is an “ID” leads to some confusion, as shown below:

 

In the above screen-shot there are two different methods of certificate filename:

  1. Certificate with the Server name and the unique Id (e.g. QuickStart Data Access Server [B59….].der)

  2. Certificate with the unique Id (e.g. [047448….].der)
