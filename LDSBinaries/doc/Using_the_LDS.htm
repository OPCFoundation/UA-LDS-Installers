OPC UA Local Discovery Server 1.02

Launching the LDS

The LDS executable is called "opcualds.exe".

  • Windows location: C:\Program Files (x86)\Common Files\OPC Foundation\UA\Discovery\bin\

  • Linux location: /opt/opcfoundation/lds/bin/

Command line arguments

Opcualds is also a command line program that supports the following options, visible when typing: opcualds --help

Usage: opcualds [-c configfile] [-d] [-v] [-i <account>] [-p <password>][-u] [-h] <command>

Options:

-d: Debug mode. The server sends verbose output to standard error and does not go into background.

-D: No detach. When this options is specified, ualds will not detach and does not become a daemon (or service on Windows).

-v: Prints version information.

-i: Installs the UA LDS as service (Windows only). As account you can either specify  SYSTEM,or any other user account. Use option -p to specify a password for the account.

  -p: Specifies password for service account (Windows only).

  -u: Uninstalls the UA LDS service (Windows only).

  -h: Prints the synopsis and a short description of the possible options.

Commands:

  start: Starts the Windows service.

  stop: Stops the Windows service.

  status: Prints status information about Windows service.

Note:

  • Start and stop command requires administrative privileges.

  • When debug mode (opcualds -d) is used, log level is set to debug level and this is useful for debugging problems without changing the configuration file.
