OPC UA Local Discovery Server 1.02

Certificate Repository

The LDS utilizes one certificate A PKI certificate for unique identification. These kinds of certificates are common on Websites, but can also be used to identify applications and people. repository, but features several sub-repositories for the effective management of trusted applications, trusted issuers, and rejected certificates. Each are shown below:

Windows File

C:\ProgramData\OPC Foundation\UA\Discovery\

Linux File

/opt/opcfoundation/lds/etc/

pki/own

pki/rejected

list of rejected certificates

trusted

pki/trusted

list of trusted Certificates

By default, the LDS requires a secure connection for UA Servers An OPC Server exposing an OPC UA interface. to register (via the RegisterServer call) so as to be listed by the LDS.
