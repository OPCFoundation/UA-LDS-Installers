Removing an Application from the Trust List

Removing an application from the trust The need for an application to trust another application. Trust is established via PKI Certificates. Applications that do not trust each other can reject connections to each other depending upon the security methods used. list is a simple process:

  1. Delete the certificate A PKI certificate for unique identification. These kinds of certificates are common on Websites, but can also be used to identify applications and people. from the LDS trusted list.

Once an application is removed from the trust list it will no longer be allowed to connect to the LDS. This is a mechanism that could be used for security purposes to intentionally hide UA Servers An OPC Server exposing an OPC UA interface. from the network.

Remember, if an application is not trusted when it attempts to connect to the LDS then a copy of its certificate will be placed into the rejected list.
