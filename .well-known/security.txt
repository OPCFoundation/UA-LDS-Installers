# Vulnerability handling and coordinated disclosure.
Policy: https://github.com/OPCFoundation/OPC-SecurityAdvisories

# How vulnerabilities are identified. The OPC Foundation is GCVE Numbering
# Authority 105 (https://gcve.eu/gna/105/) and assigns GCVE-105-<YEAR>-<NNNN>
# as the PRIMARY identifier, because it is the only one obtainable in a
# timeframe disclosure can work to. Not being a CNA, the Foundation also
# requests a CVE from another CNA as a SECONDARY identifier; that is often
# significantly delayed, and the advisory is reissued carrying both when it
# arrives. Do not wait for the CVE before patching - no CVE yet does not mean
# no CVE ever. GCVE namespace 0 is reserved for the CVE program, so CVEs map in
# unchanged (CVE-2023-40224 = GCVE-0-2023-40224).
Policy: https://github.com/OPCFoundation/UA-LDS-Installers/blob/master/docs/cra/cve-policy.md
